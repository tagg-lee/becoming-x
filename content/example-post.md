## Welcome to Becoming X

This is an example Markdown post. You can place `.md` and `.html` files in the `content/` folder, and they will automatically appear on the dashboard.

### How It Works

1. Add your content files to the `content/` directory
2. Include frontmatter metadata (title, tags, dates)
3. Push to GitHub — Cloudflare Pages builds and deploys automatically

### Supported Formats

- **Markdown** (`.md`): Standard YAML frontmatter with `---` delimiters
- **HTML** (`.html`): YAML metadata inside an HTML comment at the top of the file

### Tags

Use tags to organize your content. The dashboard lets you filter by tag, search by title, and sort by date.
